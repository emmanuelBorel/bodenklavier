# Experiment: Bodenkontakterkennung

## Ziel

Untersuchung, ob mit der Orbbec-Astra-Tiefenkamera zwischen

1. leerer Taste,
2. Fuß oberhalb der Taste ohne Bodenkontakt,
3. Fuß mit tatsächlichem Bodenkontakt

unterschieden werden kann.

## Messgrößen

- Referenztiefe des leeren Bodenklaviers
- aktuelle Tiefe
- Tiefendifferenz
- Anzahl veränderter Pixel
- Anteil veränderter Pixel
- minimale Tiefendifferenz
- maximale Tiefendifferenz
- mittlere Tiefendifferenz

## Zustände

- EMPTY
- HOVER
- CONTACT

## Ziel der Auswertung

Bestimmung geeigneter Merkmale und Schwellenwerte für eine robuste
Bodenkontakterkennung.
